# 星瀚助手 (xinghan-upload)

在 Cursor / VSCode 中通过**左侧树视图**管理**星瀚控制器**（ESP32 MicroPython）：上传与运行代码、查看设备文件、串口 REPL 等。

## 功能概览

主要操作在**左侧「星瀚助手」侧栏**、**编辑器/资源管理器右键菜单**（星瀚运行、星瀚停止、星瀚上传）完成。本扩展贡献的命令**不会出现在命令面板**（Cmd/Ctrl+Shift+P）中，请通过侧栏与右键使用。

### 左侧侧栏（星瀚助手）

点击左侧活动栏的 **星瀚助手** 图标，展开三个面板：

- **星瀚助手**（上栏）
  - **▶️ 星瀚运行**：在控制器上运行当前打开的文件，输出在「输出」面板；多设备时会先选择端口
  - **⏹️ 星瀚停止**：停止设备上正在运行的程序
  - **📤 星瀚上传**：将当前文件上传到选定容器（container1～container5）；多设备时会先选择端口
  - **📶 WiFi连接**：向设备发送 WiFi 连接命令（预设或手动输入）
  - **🔌 REPL连接**：选择星瀚控制器端口后在内置终端进入 REPL
  - **📴 REPL断开**：关闭 REPL 终端并释放串口，便于随后上传或运行

- **星瀚控制器**（中栏）
  - 展开 container1～container5 查看设备上的 **.py 文件**
  - **点击 .py 文件**：在编辑器中打开，可修改后 **Ctrl+S 保存回设备**
  - **右键 .py 文件 → 重命名 / 删除**：在同一容器内改名（读→写新名→删旧名），或从设备上删除该文件

- **连接状态**（下栏）
  - 初始即展示当前可用端口（星瀚控制器 `/dev/cu.usbmodem*`）
  - 标题栏 **刷新** 按钮：仅刷新端口列表展示，与是否 REPL连接无关
  - REPL连接后会显示「已连接端口」

在**已打开的本地文件**上右键（编辑器内或资源管理器中），可使用与侧栏一致的 **▶️ 星瀚运行 → ⏹️ 星瀚停止 → 📤 星瀚上传**（顺序固定）。

## 安装

### 从 VSIX 安装（推荐）

1. 下载 `xinghan-upload-0.11.1.vsix`（或从 Releases 获取）
2. 在 Cursor/VSCode 中：`Cmd+Shift+P`（Mac）或 `Ctrl+Shift+P`（Win/Linux）→ 输入 **Extensions: Install from VSIX...** → 选择 `.vsix` 文件
3. 重新加载窗口后即可使用

### 开发调试

1. 克隆或下载本仓库，在 Cursor/VSCode 中打开
2. 运行 `npm install`
3. 按 **F5** 启动扩展开发主机，在新窗口中测试

## 环境要求

- **Python 3**
- **pyserial**、**mpremote**（首次使用有线功能时插件会检测并提示安装）
- **bleak**（首次使用蓝牙功能时插件会检测并提示安装）

手动安装：`pip install pyserial mpremote bleak`

星瀚控制器通过 USB 连接后，Mac 上一般为 `/dev/cu.usbmodem*`；插件仅识别此类端口，其他串口不会在「连接状态」与「REPL连接」中显示。

## 配置（可选）

在设置中搜索「星瀚助手」可配置：

| 配置项 | 说明 | 默认 |
|--------|------|------|
| `xinghan.pythonPath` | Python 解释器 | `python3` |
| `xinghan.serialPort` | 指定串口，留空则自动检测 | 空 |
| `xinghan.bluetoothNamePrefix` | 蓝牙扫描名称前缀 | `ybc-r2` |
| `xinghan.bluetoothScanTimeout` | 蓝牙扫描超时时间（秒） | `6` |
| `xinghan.bluetoothCommandTimeout` | 蓝牙命令超时时间（秒） | `8` |
| `xinghan.bluetoothRunContainer` | 蓝牙运行临时上传容器 | `container1` |
| `xinghan.wifiPresets` | 预设 WiFi 列表（`name`、`password`、`authMode`） | 见设置说明 |

输出与日志在「输出」面板的 **星瀚助手** 通道查看。

## 打包

```bash
npm install
npm run esbuild    # 编译
npm run package    # 生成 .vsix
```

会在当前目录生成 `xinghan-upload-0.11.1.vsix`，可分发给他人安装。

### v0.11.1（当前发行版，对应 VSIX / 市场版本）
- **侧栏文案**：「联网」更名为「WiFi连接」，「连接 REPL / 断开 REPL」统一为「REPL连接 / REPL断开」
- **WiFi 预设**：新增 `XC的iPhone` 默认 WiFi 配置

### v0.11.0
- **蓝牙连接**：优化蓝牙连接入口与运行状态展示

### v0.10.0
- **蓝牙模式**：新增基于 BLE Nordic UART Service 的蓝牙连接，设备名默认按 `ybc-r2` 前缀筛选
- **蓝牙上传 / 运行 / 停止**：连接蓝牙后，运行、停止、上传优先通过蓝牙 NUS 文本透传执行；未连接蓝牙时仍默认使用 USB 有线流程
- **侧栏交互**：蓝牙连接与断开合并为一个动态按钮；扫描过程会在「输出」面板显示进度提示
- **文件管理边界**：控制器文件树仍优先使用 USB 有线连接，蓝牙模式不管理设备文件

### v0.9.5
- **命令面板**：所有 `xinghan.*` 命令从 Cmd/Ctrl+Shift+P 中隐藏（`commandPalette` + `when: false`），侧栏与右键不受影响
- **星瀚控制器**：设备 `.py` 文件右键 **重命名**（`wired_uploader.py --rename`）；若活动编辑器正打开该设备文件，成功后切换为新文件名对应文档
- **星瀚助手**侧栏：去掉每项左侧 ThemeIcon，文案使用 emoji（运行 / 停止 / 上传 / WiFi连接 / REPL连接 / REPL断开）；运行、停止、上传、重命名等命令标题不再使用 Codicon，避免与 emoji 重复
- **Explorer / 编辑器右键**：星瀚运行、星瀚停止、星瀚上传（顺序固定）；此前版本已移除底部状态栏三按钮

### v0.9.4
- **星瀚运行 / 星瀚停止 / 星瀚上传**：命令与侧栏展示增加 emoji（▶️ ⏹️ 📤），并为命令注册 Codicon，便于右键菜单与命令面板识别
